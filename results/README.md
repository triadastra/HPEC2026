# Archived result tables

These files are unchanged downloads from the pinned model archive, not regenerated
metrics. `SOURCES.json` records original paths and checksums. File names describing
flat/ND and aggregate/identity refer to the source shards; see the rows for scope.
Do not combine tables without handling overlapping runs and diagnostic arms.
See `../REPRODUCING.md` and `../docs/audit/` for data-version, provenance, LR-selection
and cost limitations. `model_cost_FINAL.csv` retains its original archival name.
